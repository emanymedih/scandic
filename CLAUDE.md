# Контекст проекта: журнал скандинавской ходьбы

Отвечай пользователю по-русски. Пользователь просит спорить и предлагать свои решения, если они обоснованы. Объясняй, почему считаешь своё обоснование верным.

## Правила доктора (приоритет над любыми источниками)

- Три выхода в неделю.
- Прибавка времени в нагрузке — **не более 5 минут за неделю**.
- Не выяснено, «+5 мин» — это на одну прогулку или на неделю в сумме. Сейчас считаем на одну прогулку. Вопрос открыт.
- Ориентир на неделю задаёт пользователь с доктором. Страница только подсказывает и никогда не ставит ориентир сама.
- Целевой диапазон Борга и пульса не назначен. Не придумывай его.

## Принцип работы

Любые изменения логики и структуры опираются на исследования и руководства. Источник ссылкой указывается в интерфейсе (вкладка «Основания»). Форумы и блоги годятся только для практических советов (техника, экипировка), но не для норм нагрузки. Если порог — допущение без источника, так и пиши.

## Данные и определения

- **Время в нагрузке** = длительность часов − остановки. «Длительность» в Huawei Health (часы HUAWEI WATCH GT 3 Pro) включает остановки: таймер идёт, пока каденс 0. Остановки оцениваются по графику каденса. Пусто — значит «не оценены», и тогда время в нагрузке равно длительности.
- **Полное время** = длительность часов. **Темп** = полное время / км.
- **Борг 6–20**: шкала общего усилия.
- **Утром след. дня, 0–10**: отклонение от обычного самочувствия.
- **Симптомы** — список. «Боль/давление в груди», «Головокружение» и «Сердцебиение/перебои» — тревожные, по ним показывается «Стоп: обсудить с доктором».
- Пульс с запястья при работе палками неточен (до ±5 уд/мин), поэтому смотрим тренд, а не разницу двух прогулок.
- Неделя считается с понедельника по воскресенье. Даты хранятся в формате ISO `YYYY-MM-DD`, показываются как `ДД.ММ.ГГГГ`.
- Исходное время до начала учёта ≈ 10 мин на прогулку (сентябрь — начало октября 2026, нерегулярно). Используется только для «прибавки» первой недели.

## Рекомендация на следующую неделю (порядок проверки)

1. Есть тревожный симптом → «Стоп: обсудить с доктором».
2. Нет ориентира → «Нет ориентира».
3. Не у всех прогулок есть Борг или утренняя оценка → «Заполните…».
4. Выходов меньше `req` (3), Борг > `borg` (13), утро > `morning` (2), любые симптомы кроме «Нет» или прогулка короче ориентира − `tol` (1) → «Держать N мин».
5. Ориентир ≥ `goal` (30) → «Цель этапа достигнута — к доктору».
6. Иначе → «Можно min(N + step, goal) мин», где `step` = 5.

Пока неделя идёт и выходов меньше 3, показывается «Неделя идёт».

Происхождение порогов:
- `step`, `req` — правила доктора;
- `borg` 13 — руководство PCNA (11–13);
- `goal` 30 — начальный этап по ACSM (PCNA: 20–40 мин);
- `morning` 2 и `tol` 1 — **допущения без источника**, так и помечены.

Правило «+10% в неделю» сознательно не используется: в RCT Buist et al., 2008 оно не снизило число травм.

## Устройство страницы

- `index.html` — один файл без сборки. Первый `<script>` содержит чистую логику (`L`, экспортируется через `module.exports` для тестов в Node), второй — интерфейс.
- Страница опубликована как артефакт Claude и хранит данные во встроенном хранилище (`window.claude.use("db")`):
  - коллекция `walks`, id документа — дата;
  - поля: `date`, `start`, `durSec`, `stopsSec`, `km`, `hr`, `hrMax`, `tempC`, `borg`, `symptom`, `morning`, `note` и необязательный объект `watch` с полными данными часов;
  - документ `settings/plan`: `startWeek`, `targets{неделя: мин}`, `reasons{неделя: текст}`, `params{step, req, borg, morning, tol, goal, baseline}`.
- Вне Claude хранилища нет, и страница работает только для чтения. Возможное улучшение — запасное хранение в `localStorage` с тем же форматом данных и экспортом/импортом в JSON.
- Логику проверяй в Node на примерах. Ожидаемые значения на исходных данных:
  - прогулки: 16,1 / 17,4 / 17,8 мин;
  - неделя 05.10: прибавка +7,4, «Заполните Борг (0 из 2)»;
  - неделя 12.10: прибавка +0,4;
  - следующий выход — через день после последней прогулки.

## Конфиденциальность

Репозиторий **публичный**. Не коммить записи о прогулках, пульс, симптомы и другие данные о здоровье. Они остаются в хранилище артефакта. Выгружать их можно только с явного согласия пользователя и только в приватное место.

## Источники (уже используются на вкладке «Основания»)

- Church, Earnest, Morss, 2002 — с палками кислорода на ~20% больше, пульс на 5–8 уд/мин выше, а субъективная тяжесть не растёт.
- Barberan-Garcia et al., 2015 (ХОБЛ) — то же.
- Дневник кардиореабилитации Kaiser Permanente — шкала Борга 6–20 и список симптомов.
- Silbernagel et al., 2007 — модель контроля боли: взята только форма утренней оценки.
- Опрос клиник кардиореабилитации США (PMC8938824) — прибавку запускает устойчиво низкий Борг (56%), сначала растёт длительность (78%).
- PCNA — Борг 11–13, talk test, тревожные симптомы.
- ACSM — начальный этап до ~30 мин, +5–10 мин раз в 1–2 недели, одна переменная за раз.
- Scand J Med Sci Sports — точность оптических датчиков пульса.
- Buist et al., 2008 — правило 10%.
