# Журнал скандинавской ходьбы

Страница для учёта прогулок со скандинавскими палками: данные с часов, субъективная нагрузка, самочувствие и недельные ориентиры, согласованные с доктором.

## Что внутри

`index.html` — одна самодостаточная страница (HTML, CSS и JS в одном файле, без сборки).

- **Прогулки.** Форма для данных с часов: длительность, остановки, км, пульс, °C. Плюс шкала Борга 6–20, симптомы, утренняя оценка 0–10 и заметка. Время в нагрузке = длительность − остановки, темп считается сам. Есть график «время в нагрузке против ориентира недели».
- **Недели.** Ориентир на выход, три выхода, сумма, фактическая прибавка к прошлой неделе (больше 5 мин подсвечивается), состояние недели и подсказка на следующую неделю. Ниже — итоги по месяцам.
- **Прогрессия.** Настраиваемые условия прибавки: шаг, число выходов, порог Борга, утренняя оценка, допуск, цель этапа. Самая ранняя неделя достижения цели и вопросы доктору.
- **Основания.** Почему журнал устроен именно так, со ссылками на исследования и руководства.

## Где хранятся данные

Страница сделана как артефакт Claude и сохраняет записи в его встроенном хранилище (возможность `db`, коллекции `walks` и `settings/plan`). Если открыть файл вне Claude, например локально или через GitHub Pages, хранилища нет: страница откроется пустой и предупредит, что записи не сохраняются.

Сами записи о прогулках в репозиторий не входят, потому что это личные данные о здоровье, а репозиторий публичный.

## Логика рекомендации на следующую неделю

Проверки идут по порядку, срабатывает первая подходящая:

1. Боль или давление в груди, головокружение, перебои → «Стоп: обсудить с доктором».
2. Нет Борга или утренней оценки → «Заполните…».
3. Меньше 3 выходов, Борг выше порога (13), утром хуже порога (2), любые симптомы или выход короче ориентира больше чем на 1 мин → «Держать N мин».
4. Иначе → «Можно N + 5 мин», но не больше цели этапа (30 мин).

Это подсказка, а не назначение: ориентир задаёт доктор.
